# NulaCare Go — Android beta

Installable builds of the NulaCare Go Android app. The source lives in a private
repository; this one only hosts release binaries, so testers get a stable link.

**Latest download**

https://github.com/NulaCare/nulacare-android-releases/releases/latest/download/nulacare-go-android.apk

## Install

1. Download the APK on an Android phone (Android 8.0 or newer).
2. Your browser will warn about installing from an unknown source — allow it for
   that browser. The app is signed with NulaCare's release key, but it is not
   distributed through Google Play yet.
3. Open the APK and install. Upgrades install over the previous version and keep
   your data.

## What this build is

- Opt-in anonymous usage statistics, off by default.
- No account: everything is stored on the device. Deleting the app deletes the log.
- A self-management journal. It is not a medical device and does not give medical
  advice; associations are shown with their uncertainty, never as verdicts.
